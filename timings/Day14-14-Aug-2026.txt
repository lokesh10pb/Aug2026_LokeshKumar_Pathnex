# 14 August – Day 14

## AWS EKS Practical Session (3 Hours)

* Attend the AWS EKS practical session.
* Learn what Amazon EKS is and why it is used.
* Understand how Kubernetes works with AWS EKS.
* Learn the basic architecture of an EKS cluster.
* Understand the role of the EKS Control Plane and Worker Nodes.
* Learn how to create an EKS cluster step by step.
* Understand the required IAM roles and permissions.
* Learn how VPC, Subnets, and Security Groups are used with EKS.
* Create an EKS cluster.
* Create and configure the Node Group.
* Connect to the EKS cluster using `kubectl`.
* Update the kubeconfig for the EKS cluster.
* Check the cluster nodes and verify the setup.
* Deploy a basic application on the EKS cluster.
* Take proper notes during the practical session.
* Write down important commands, interview points, and practical steps.

Basic flow:

AWS Account → IAM → VPC / Subnets → EKS Cluster → Node Group → kubeconfig → kubectl → Deploy Application
